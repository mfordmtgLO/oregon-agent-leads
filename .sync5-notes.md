# Sync 5 review — "Add principal broker records to Oregon directory sync"

Commit e75059e (incoming from GitHub) does two things:

1. `server/syncExport.ts` — broker links changed from agent-list lookup to a new
   `?principalBroker=<encoded name>` deep link. Brokers are now emitted as their own
   `recordType: "principal_broker"` records with `rankKind: "office"`, negative stable
   ids, deduped case-insensitively, sorted by office rank. Payload gains
   `topAgentCount` / `principalBrokerCount`.
2. `client/src/pages/Dashboard.tsx` — derives a principal-broker directory client-side and
   merges it into the Agent Index list (`directoryRecords`), supports `?principalBroker=`
   deep links, heading now reads "60 top agents + 37 principal brokers".
