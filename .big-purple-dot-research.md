# Big Purple Dot integration assessment

Official site: https://www.bigpurpledot.com/
BPD Recruit: https://recruit.bigpurpledot.com/

The public Big Purple Dot site describes AI and recruiting intelligence plus CRM products for real-estate and mortgage professionals. Publicly documented capabilities include lead management, partner collaboration, CRM workflows, notes, documents, and an Optimal Blue point-of-sale integration. The page does not expose a generic public API reference, webhook schema, or developer-key instructions.

The public home page explicitly links to BPD Recruit and says it is a recruiting product. Exact data fields, API access, event hooks, exports, account scopes, and commercial-use permissions need confirmation from the authenticated BPD Recruit/Big Purple Dot support or sales team before implementation. Do not scrape the login page or guess undocumented endpoints.

Design implication: build an integration-ready connection panel with provider, environment, official base URL, auth method, secret-backed credentials, connection test, last sync, sync errors, data scope, retention, and source/licensing acknowledgement. Prefer an official API or event hook; accept a licensed CSV/JSON export as a fallback. Raw imported records should remain separate from curated Oregon records and feed the existing normalization, deduplication, LO/agent matching, and review queue.

The public site was inspected on 2026-09-03. It supports the product direction but is not sufficient to activate a live connector without account-specific documentation and permission.
