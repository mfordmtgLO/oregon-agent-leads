# MMI integration research

- Official MMI Data Center page: https://mmi.io/mmi-data-center/
- MMI states its Agent Transaction History can show LOs previously working with buyside, listside, and dualside agents; it supports filters by city, volume, and transactions.
- MMI states LO Rank & Search can search by LO name or NMLS, lender roster, geography, loan type, production volume, and timeframe; it describes Fast Fact profiles with loan history and performance.
- MMI states agent tracking, Matchmaker, wallet-share analysis, and recruiting research are available product capabilities.
- MMI states Enhanced Profiles can retrieve phone/email when available and says this feature is Premier Enterprise only.
- MMI states CRM Sync uses webhooks to connect to a CRM with an open API or Zapier integration.
- MMI official home page shows example entity fields for real-estate agents, loan officers, lenders, and offices, including sold counts/volume, loan volume/transactions, purchase/refi, agent count, office sold transactions, buy-side/list-side/double-sided counts.
- MMI Help Center is at https://help.mmi.io/ and support is at https://support.mmi.io/.
- Public site pages do not expose a complete public API reference or generic developer key instructions. A July 2026 support search result says event hook, webhook, and API docs are live in-app; access and exact schemas should be confirmed with MMI for the user's account/plan.
- Integration design implication: use official account-approved API/event hook/export only; do not scrape the logged-in web app or store raw MMI passwords. Keep raw imported records, source timestamps, provider IDs, normalized entities, match evidence, and review status separate from curated Oregon agent records.
