## False positives found and fixed during live testing
1. Legit sites flagged "blocked" because raw HTML contained reCAPTCHA i18n keys
   (`{"captcha":"Captcha"}`) — e.g. leachitwood.com, judehodgebroker.com,
   hannahkatz-professionalgroup.sites.cbmoxi.com. Fix: `looksBlocked` matches visible
   text only and requires a short page (<4k chars).
2. Lea Chitwood falsely "changed" to "The Real Brokerage Inc." — that name normalizes
   to the single word "real", which matched inside "really" in a testimonial. Fix:
   whole-word matching (`containsOrgPhrase`) + `isDistinctiveOrgName` rejects single
   generic words.
3. "RE/MAX Power Pros" (record) vs "REMAX PowerPros" (page) failed to match. Fix:
   despaced fallback comparison for multi-word names.
